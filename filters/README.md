# Built-in filter groups

Generated by `make filter` from the `*.filter` files in this folder: edit those, not
this file (`go test` fails while it is stale).

Each file is a rules file in the filter syntax shared with targy, see the
**filter** command in the main README. A filter adds a group with `use NAME`,
or `--use NAME` on the command line. A group that combines others has only
`use` lines: a tool reading these files directly resolves `use NAME` as
`NAME.filter` in this folder, or runs `autoversion filter dump --use NAME` for
the group flat. File-name rules are typed (`f:`), so a folder named `x.tmp`
or `x.mp3` is kept.

## agents: regenerable state of coding agents; transcripts and memories stay in

`use agents`, [agents.filter](agents.filter)

```
exclude /**/.claude/{debug,file-history,shell-snapshots,telemetry,logs,jobs}
exclude /**/.codex/{cache,.tmp,plugins,computer-use,generated_images,vendor_imports}
exclude f:/**/.codex/{logs_*.sqlite,thread_history_*.sqlite}
exclude /**/.ateam/{cache,logs}
```
