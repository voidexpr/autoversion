# Built-in filter groups

Generated by `make filter` from the `*.filter` files in this folder: edit those, not
this file (`go test` fails while it is stale).

Each file is a rules file in the filter syntax shared with ownit, see the
**filter** command in the main README. A filter adds a group with `use NAME`,
or `--use NAME` on the command line. A group that combines others has only
`use` lines: a tool reading these files directly resolves `use NAME` as
`NAME.filter` in this folder, or runs `autoversion filter dump --use NAME` for
the group flat. File-name rules are typed (`f:`), so a folder named `x.old`
or `x.mp3` is kept.

## build: build outputs and compiled files

`use build`, [build.filter](build.filter)

```
exclude /**/{build,dist,out}/*
exclude /**/target/{debug,release}
exclude /**/{.build,DerivedData}
exclude f:/**/{*.o,*.obj,*.so,*.a,*.lib,*.sym,*.dylib,*.rlib,*.rmeta,*.dll,*.exe,*.pdb,*.ilk,*.exp,*.gch,*.pch,*.d,*.depend}
exclude f:/**/{*.class,*.jar,*.war,*.ear,*.pyc,*.beam}
```

## caches: caches and test reports

`use caches`, [caches.filter](caches.filter)

```
exclude /**/{.cache,.next,.nuxt,.output,.pytest_cache,.playwright-mcp,playwright-report,test-results}
```

## data: database folders and write-ahead logs

`use data`, [data.filter](data.filter)

```
exclude /**/{pgdata,*.pgdb}
exclude f:/**/*.wal
```

## default: the groups applied unless a filter says otherwise

`use default`, [default.filter](default.filter)

```
use os
use editors
use temp
use logs
use build
use deps
use caches
use data
use vcs
```
